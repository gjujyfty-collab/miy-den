# Мій день

Мінімалістичний тайм-менеджер українською для Windows.

## Можливості
- Додавання, видалення та позначення завдань як виконаних.
- Пріоритети: високий, звичайний, низький.
- Індикатор прогресу.
- Таймер фокусування на 25 хвилин і перерви на 5 хвилин.
- Автоматичне збереження завдань між запусками.

## Завантажити EXE
1. Відкрийте вкладку **Actions** у цьому репозиторії.
2. Виберіть останній успішний запуск **Build Windows EXE**.
3. Унизу сторінки в секції **Artifacts** завантажте **MiyDen-Windows**.
4. Розпакуйте ZIP-архів і запустіть `MiyDen.exe`.

Збірка запускається автоматично після змін у гілці `main`. Також її можна запустити вручну через **Actions → Build Windows EXE → Run workflow**.

## Дані
Завдання зберігаються локально: `%APPDATA%\MiyDen\tasks.json`.

## Запустити з Python
Потрібен Python 3.10 або новіший:
```bash
python app.py
```
